## Cambios realizados

### 1. Corrección del archivo de datos geográficos (`municipios.geojson`)

**Problema:** 148 municipios de Antioquia (125) y Atlántico (23) tenían el campo `d` (código de departamento) con un valor incorrecto. El campo contenía los dígitos 1-2 del código DIVIPOLA del municipio en lugar de los primeros 2 dígitos.

**Ejemplo:**
- Medellín: `m = "05001"` → `d = "50"` (incorrecto) → corregido a `d = "05"`
- Barranquilla: `m = "08001"` → `d = "80"` (incorrecto) → corregido a `d = "08"`

**Corrección:** Script Node.js que recorre todos los features, detecta aquellos cuyo `m` empieza por `"05"` u `"08"` y asigna `d = m.substring(0, 2)`.

---

### 2. Mejora del filtro de municipios en modo detalle

**Problema:** El filtro `parseInt(f.properties.d, 10) === deptNum` era frágil ante variaciones de tipo (string / number) y prefijos cero.

**Corrección en `cargarMunicipiosDetalle()`:**
```typescript
const dept2 = this.detalleDepto!.codigoDepto.substring(0, 2).padStart(2, '0');
const features = this.municipiosGeoJSON.features.filter((f: any) => {
  const fDept = String(f.properties.d ?? '').padStart(2, '0');
  return fDept === dept2;
});
```

Normaliza ambos lados a string de 2 dígitos con cero a la izquierda, eliminando la ambigüedad de `parseInt`.

### 4. Código de departamento en el encabezado del modo detalle

El header ahora muestra el nombre y el código de 2 dígitos: **ANTIOQUIA (05)**. Facilita la verificación visual del código utilizado en las consultas al API.

---

### 5. Clic en municipio: carga de datos a nivel municipal

**Nueva funcionalidad:** Al hacer clic en un municipio dentro del modo detalle, el sistema:

1. Resalta el municipio en el mapa (borde azul oscuro, mayor opacidad)
2. Llama al endpoint con el código del municipio:
   `GET /geovisor/resumen_geovisor/{vigencia}/{codigoDept}/{codigoMunicipio}`
   - Ejemplo: `.../2026/05000/05001` para Medellín
3. Actualiza el panel lateral con datos SGR / SGP / PGN del municipio seleccionado
4. Muestra breadcrumb en el header: **ANTIOQUIA (05) › MEDELLÍN (05001)**
5. Clic en el nombre del departamento en el breadcrumb vuelve al nivel departamental
